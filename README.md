This is a slop-coded (via Google Gemini 3.1 Pro) wrapper around [PgsToSrt](https://github.com/Tentacule/PgsToSrt), [mkvmerge](https://www.matroska.org/downloads/mkvtoolnix.html), and [ffmpeg](https://ffmpeg.org) to allow fast OCR of PGS subtitles (frequently found on blu-ray media) to SRT.

Many media players, for example the Media Player app on LG WebOS TVs, doesn't support PGS. Those can also look quite ugly even when they work, since they're just raster images.

Note that if your media file contains more than english subtitles, you'll want to look into [this PgsToSrt issue](https://github.com/Tentacule/PgsToSrt/issues/64) to make sure you have more languages available, or pay attention to the arguments to `subfix.py` to direct it to look at english only.

---

Quick start: create a python virtual environment, and install the [srt](https://pypi.org/project/srt) module. Run subfix.py with it against an MKV or MP4 file. This will:
1. Find all the PGS subtitles in the file.
2. Run PgsToSrt to OCR the PGS subtitles to SRT
3. Remux the file to replace the converted subtitles.

You can also drive `pgstosrt.py` manually if you'd like more control. Normally subfix.py will do it for you.
